## Structural items still open

These items require a Firefox source rebase, a working FF150 binary
on the same host as Camoufox, or sustained upstream contribution and
are intentionally not in scope for the 2026-05-25 pass:

- **Real Firefox 150 baseline capture** — `tests/fingerprint_parity/
  baseline_stock_firefox_150.json` ships as a schema-shaped placeholder.
  Regenerate against a real stock FF150 install (see harness README)
  before relying on the parity check for go/no-go decisions.
- **CI wiring of the parity harness** — needs the build matrix to
  produce a runnable `camoufox-bin` artefact in the same workflow.
  Skeleton job is documented in
  `tests/fingerprint_parity/README.md`.
- **utls upstream contribution** — `firefoxBaselineIdentity()` is a
  static FF135-derived spec, not a verified FF150 ClientHello capture.
  Once the parity harness has real FF150 captures, contribute a
  `HelloFirefox_150` preset back to refraction-networking/utls so the
  static spec can go away.
- **Mozilla beta-channel drift** — the audited
  `http2-fingerprint.patch` anchors were validated against
  mozilla-beta tip on 2026-05-18. Subsequent FF point releases may
  shift the four target lines; the `apply-check` job is the canary.
