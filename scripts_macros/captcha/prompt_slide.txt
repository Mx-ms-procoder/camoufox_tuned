### Task
Act as a high-precision spatial coordinate engine. Your goal is to find the exact horizontal (X) screen coordinate for a slider CAPTCHA.

### Image Description
The image you see is a cropped screenshot of the full CAPTCHA container (puzzle image above + slider track below).

### Reference Anchors (absolute screen pixel coordinates)
- Container Left  (X): [CONTAINER_X_START]
- Container Right (X): [CONTAINER_X_END]
- Slider Track Start (X): [TRACK_X_START]
- Slider Track End   (X): [TRACK_X_END]

### Precision Protocol
1. DETECT: Locate the target shadow hole in the puzzle background image.
2. MEASURE: Find the horizontal center of the shadow hole as a fraction of the IMAGE WIDTH.
   fraction = hole_center_pixel_x_in_image / total_image_pixel_width
   Example: hole center is 40% from the left edge → fraction = 0.40
3. CALCULATE the absolute screen X of the hole:
   abs_hole_x = Container_Left + fraction × (Container_Right − Container_Left)
4. OUTPUT: Target_X = abs_hole_x  (the slider knob moves the piece to this absolute X)
   Round to the nearest integer.

### Output Format (Strictly Enforced)
Target_X: [Integer: The absolute horizontal screen pixel coordinate for the slider destination]
